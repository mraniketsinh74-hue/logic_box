# Logic Box – Pattern Generator and Number Analyzer

## Project Overview

Logic Box is a simple Python-based console program called **Pattern Generator and Number Analyzer**.

The project is designed to practice basic Python programming concepts such as loops, conditional statements, control statements, input validation, and nested loops.

The program provides a menu-driven interface where the user can:

1. Generate a right-angled triangle pattern.
2. Analyze a range of numbers.
3. Exit the program.

---

## Objective

The main objective of this project is to understand and implement:

- `for` loops
- `while` loops
- Nested loops
- `range()` function
- `if-else` statements
- `break` statement
- `continue` statement
- `pass` statement
- Input validation
- Exception handling
- Menu-driven programming
